# 定时提醒 · 使用说明（简短版）

循环提醒 + 一次性提醒 App：到点弹通知 / 全屏闹钟响铃，支持多任务并行。

## 安装

- **APK 文件**：`release\TimerReminder.apk`（或从 GitHub Releases 下载）
- 传到手机点开安装，首次需允许"安装未知来源应用"
- 支持 Android 8.0 及以上

## 第一次使用：先授权（关键！）

打开 App，按顶部「**需要授权**」卡片逐项处理（也可点右上角「使用说明」查看）：

| 授权 | 作用 |
| --- | --- |
| 通知权限 | 到点弹出提醒通知（必开，不开不提醒） |
| 电池优化白名单 | 息屏/后台不被系统延迟或杀掉提醒（强烈建议） |
| 全屏闹钟权限 | 锁屏时自动弹出全屏闹钟页（Android 14+ 需在系统设置里开「闹钟和提醒」） |
| 后台弹出界面权限 | 后台时能直接弹出全屏闹钟页（**国产手机必开**，不开后台时全屏闹钟会被拦截，只显示通知） |
| 锁屏显示权限 | 锁屏时显示全屏闹钟界面（不开可能只响铃不显示界面，需在系统设置允许「锁屏显示」） |

国产手机（小米/华为/OPPO/vivo/荣耀）另需：系统设置 → 应用管理 → 定时提醒 → **允许自启动 / 后台运行**，否则退出后可能收不到提醒。

## 怎么添加提醒

点右下角 **＋**：

- **循环提醒**：设间隔（1~9999 分钟），可选**截止时间**（到点自动停止）
- **一次性**：选日期+时间，到点提醒一次，之后标记「已完成」
- **提醒方式**：通知 / 全屏闹钟 / 两者
- 响铃、震动、保存后立即启用，都可单独开关

## 任务卡片操作

- **开关**：启用/暂停该任务
- **立即测试**：马上试一次提醒效果（不影响正常计时）
- **编辑 / 删除**：修改或移除任务
- 已结束的任务（循环到期 / 一次性完成）显示「已到期 / 已完成」，编辑后可重新启用

## 常见问题：到点没提醒？

按顺序检查：
1. 通知权限是否已开（App 顶部卡片或系统设置 → 通知 → 定时提醒）
2. 电池优化白名单是否已加入（系统设置 → 电池 → 应用省电策略 → 不限制）
3. 国产手机是否允许自启动/后台运行
4. 是否开了勿扰模式 / 静音
5. 息屏较久时，系统省电可能延迟提醒——加入电池白名单可基本解决

## 数据说明

- 任务设置保存在手机本地，卸载 App 会清除
- 重启手机后闹钟会自动恢复，无需重新设置
