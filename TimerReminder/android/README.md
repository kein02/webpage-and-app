# 定时提醒 App（Android 原生版）

中文界面 · 循环提醒（1 ~ 9999 分钟）· 循环截止时间 · 一次性提醒 · 通知 + 全屏闹钟

| 项 | 值 |
| --- | --- |
| 包名 | `com.example.timereminder` |
| 最低系统 | Android 8.0（API 26） |
| 目标系统 | Android 16（API 36） |
| 技术栈 | Kotlin 2.2.10 + Jetpack Compose + AlarmManager + 前台服务 |
| 编译环境 | AGP 8.13.0 / Gradle 8.14.3 / JDK 21 |
| 界面风格 | 清新浅色（蓝绿主色） |

## 功能一览

- **循环提醒**：每个任务独立循环，间隔 1 ~ 9999 分钟（任意整数），多任务并行互不影响
- **循环截止时间**：编辑时可选截止日期+时间，到点自动停止，列表标记「已到期」
- **一次性提醒**：编辑时选「一次性」，指定日期+时间，到点提醒一次后标记「已完成」（保留在列表，可编辑重新启用）
- **提醒方式**：通知 / 全屏闹钟 / 两者都要；声音与震动可逐任务配置
- **全屏闹钟**：锁屏弹出全屏页 + 持续响铃，点「停止响铃」才停
- **立即测试**：任务卡片按钮，立即触发一次提醒表现，不影响正常调度
- **使用说明**：顶栏「使用说明」按钮，逐项说明需要开启的权限与设置路径

## 用 Android Studio 打开

1. 打开 Android Studio → **File → Open** → 选择本目录（含 `settings.gradle.kts` 的 `android/` 文件夹）
2. 等待 Gradle 同步完成（首次会自动下载依赖，需要联网）
3. 菜单 **Build → Build APK(s) → Build APK(s)** 即可在 `app/build/outputs/apk/debug/` 生成 debug APK
4. 真机/模拟器：连接设备（开启 USB 调试）后点 ▶ 运行

## 首次使用权限引导（重要）

App 内置「需要授权」提示卡片，按提示逐项授权：

| 权限 | 用途 | 说明 |
| --- | --- | --- |
| 通知权限 | 弹出提醒通知 | Android 13+ 首次打开会弹系统授权框；若拒绝，点卡片「去授权」 |
| 精确闹钟权限 | 准点触发 | Android 12+ 需在系统设置中授予「闹钟和提醒」；不授予也能用但可能延迟 |
| 全屏闹钟权限 | 锁屏时弹全屏闹钟页 | Android 14+ 需在系统设置中授予「闹钟和提醒」类别；不授予时锁屏只响铃不弹页 |
| 电池优化白名单 | 防后台被杀/延迟 | 打开 App 后点权限卡片「去授权」，系统会弹窗确认加入白名单；小米/华为等国产 ROM 还需在系统设置中允许自启动 |
| 锁屏通知 | 锁屏时显示提醒 | 系统设置 → 通知 → 定时提醒 → 允许锁屏显示 |
| 勿扰模式 | 勿扰时静默 | 到点不响可检查是否开了勿扰/静音模式 |

## 真机验收清单

- [ ] 添加任务（每 1 分钟、通知方式）→ 1 分钟后收到系统通知（有声音/震动，可配静音）
- [ ] 添加任务（每 2 分钟、全屏闹钟方式）→ 到点弹出全屏闹钟页并持续响铃，点「停止响铃」后停止
- [ ] 添加任务（每 5 分钟、两者都要）→ 同时收到通知 + 弹全屏闹钟
- [ ] 多任务并行：两个不同间隔的任务各自独立循环，互不影响
- [ ] 暂停任务 → 到点不再提醒；恢复任务 → 从当前时间重新计间隔
- [ ] 编辑间隔/提醒方式 → 保存后按新配置生效
- [ ] 删除任务 → 不再提醒
- [ ] 锁屏状态下到点 → 屏幕亮起弹出全屏闹钟（需已授予全屏闹钟权限）
- [ ] 杀进程（从最近任务划掉）后到点 → 仍能提醒（闹钟走系统调度）
- [ ] 重启手机后到点 → 仍能提醒（开机自动恢复闹钟）
- [ ] 点击通知 → 打开 App
- [ ] 每 1 分钟任务持续运行 10 分钟 → 每分钟都触发一次（循环验证）

## 打包 APK

### Debug 包（直接安装测试）

Android Studio：**Build → Build APK(s)**
或命令行（需先配置 JAVA_HOME 指向 Android Studio 的 jbr）：

```bat
set JAVA_HOME=D:\Android Studio\jbr
gradlew.bat assembleDebug
```

产物：`app\build\outputs\apk\debug\app-debug.apk`

### Release 包（正式签名，可分享安装）

**签名已配置好**，直接构建即可：

```bat
set JAVA_HOME=D:\Android Studio\jbr
gradlew.bat assembleRelease
```

产物：`app\build\outputs\apk\release\app-release.apk`

或用 Android Studio：**Build → Generate Signed App Bundle / APK…** → 选 **APK** → 使用现有密钥 `android\keystore\timereminder.jks`。

> ⚠️ **密钥必须妥善保存**：`keystore\timereminder.jks` 与密码（见 `keystore.properties`）是以后**升级版本覆盖安装**的唯一凭证，丢了就无法再更新已安装的 App（只能卸载重装，会丢数据）。建议把密钥文件和密码备份到安全的地方（网盘/移动硬盘），不要发给别人。
>
> 提示：release 包未启用混淆（isMinifyEnabled=false），不影响功能。

## 行为规则（与浏览器原型一致）

- 循环调度：每次触发后自动安排下一次（`nextAt = now + 间隔`）
- 任务独立：每个任务一个 PendingIntent（Intent data 隔离），互不覆盖
- 触发顺序：先重排下一次 → 再保存 → 再提醒
- 编辑间隔或暂停/恢复后，从当前时刻重新计间隔

## 后台/锁屏提醒排查（重要）

代码层面已做处理：
- 全屏闹钟：Android 12+ 后台启动前台服务受限时，自动降级为全屏通知 + 全屏页兜底播放铃声
- App 内权限卡片引导：通知 / 精确闹钟 / 全屏闹钟 / 电池优化白名单

若仍出现"退出后不提醒 / 锁屏不提醒"，按序检查：
1. **电池优化白名单**：打开 App → 顶部「需要授权」卡片 → 电池优化「去授权」（系统弹窗点允许）；或在系统设置 → 电池 → 应用省电策略 → 不限制
2. **精确闹钟权限**：同卡片「去授权」；Android 12+ 在系统设置 → 特殊权限 → 闹钟和提醒
3. **自启动/后台**（小米/华为/OPPO/vivo/荣耀等国产 ROM 必查）：系统设置 → 应用管理 → 定时提醒 → 自启动/后台运行/锁屏清理全部允许
4. **通知权限 + 锁屏通知**：系统设置 → 通知 → 定时提醒 → 允许通知、允许锁屏显示
5. **勿扰/静音**：勿扰模式下通知会被静音或拦截
6. **Doze 深度休眠**：长时间静止锁屏后，未豁免电池优化的 App 会被限制；加入白名单可解决

> 说明：Android 系统对后台应用的调度有硬性限制（Doze 模式、后台限制），任何 App（包括系统闹钟）在极端省电场景都可能延迟，加入电池白名单 + 自启动是最有效的缓解手段。
