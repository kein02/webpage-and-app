# 定时提醒 · 浏览器原型

先在浏览器里体验完整功能，确认无误后，原生 Android 版将按同样的交互与逻辑实现。

## 快速开始

**方式一（最简单）**：双击打开 `index.html`，用 Chrome/Edge 测试即可。

**方式二（本地服务器）**：

```bash
cd web-prototype
npx http-server .          # 或任意静态服务器
# 打开 http://127.0.0.1:8080
```

## 功能说明

| 功能 | 说明 |
| --- | --- |
| 循环提醒 | 每个任务独立循环，间隔 1 ~ 9999 分钟（任意整数），多任务并行互不影响 |
| 提醒方式 | 通知横幅 / 全屏闹钟 / 两者都要 |
| 通知横幅 | 页面顶部横幅，5 秒自动消失或手动关闭；可配响铃、震动 |
| 全屏闹钟 | 全屏弹窗 + 持续响铃（Web Audio），点「停止响铃」才停 |
| 测试模式 | 顶栏开关，开启后 1 分钟 = 1 秒，方便快速验证循环（仅原型，打包后无此功能） |
| 立即测试 | 任务卡片按钮，立即触发一次提醒表现，不影响正常调度 |
| 持久化 | localStorage 保存，刷新/重开浏览器任务仍在 |

## 文件结构

```
web-prototype/
├── index.html       单页界面
├── style.css        样式（含全屏闹钟、横幅、开关）
├── core.js          核心纯逻辑：间隔计算、下次触发时间、任务标准化、表单校验
├── app.js           主逻辑：调度、通知、闹钟、持久化
├── test-core.js     core.js 单元测试（node test-core.js）
├── test-storage.js  持久化往返冒烟测试（node test-storage.js）
└── test-browser.js  浏览器端自动化自测（node test-browser.js，需本机 Chrome）
```
