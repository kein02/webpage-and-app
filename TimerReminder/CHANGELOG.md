- 版本号升至 1.0.1（versionCode 2）

## 1.0.0（正式发布 · 2026-08-04）

内部迭代到 v1.9 后定版为正式第一版。功能与修复累计：

**功能**
- 循环提醒：间隔 1 ~ 9999 分钟，多任务并行，可设截止时间（到期自动停止）
- 一次性提醒：指定日期+时间，到点提醒一次，完成后标记「已完成」
- 提醒方式：通知 / 全屏闹钟 / 两者；声音与震动逐任务可配
- 全屏闹钟：深蓝全屏页 + 持续响铃 + 手动停止；锁屏可弹出
- 使用说明：App 内「使用说明」逐项说明权限与设置路径
- 清新浅色主题界面

**可靠性（关键修复）**
- 闹钟调度改用系统 `setAlarmClock`：息屏/Doze 下准时触发，无需精确闹钟权限
- 触发链路三层兜底（前台服务响铃 → 全屏通知 → 尽力弹全屏页），保证至少一条路径生效
- 修复一次性任务被提前静默取消 / 未触发被误标完成的问题
- 修复任务 id 同毫秒冲突导致闹钟互相覆盖的问题
- 修复闹钟触发后前台界面不刷新（显示负计时）的问题
- 后台/锁屏触发受限时的降级通知改用系统闹钟音（响亮持久）

## 开发迭代记录（v1.0 ~ v1.9）

- **v1.0**：首个可安装版本（含启动崩溃 bug，后修复）

- **v1.7**：任务 id 冲突修复；调度改用 setAlarmClock
