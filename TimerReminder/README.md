# 定时提醒 App

> 中文界面的循环 / 一次性提醒应用：到点通知、全屏闹钟响铃、多任务并行、循环可设截止时间。手机息屏、退出应用后依然准时提醒。

| | |
| --- | --- |
| 正式版本 | 1.0.0（versionCode 1） |
| 包名 | `com.example.timereminder` |
| 支持系统 | Android 8.0+（API 26） |
| 技术栈 | Kotlin + Jetpack Compose + AlarmManager（setAlarmClock）+ 前台服务 |
| 正式包下载 | `release/TimerReminder.apk`（或 GitHub Releases） |

## 一、功能简介

### 1. 循环提醒
每个任务独立循环，间隔 **1 ~ 9999 分钟**（任意整数分钟，1 分钟到若干小时均可），多任务同时运行互不影响。

### 2. 循环截止时间
编辑循环任务时可选「截止时间」（日期 + 时间），到点后任务**自动停止**，不再提醒，状态变为「已到期」。

### 3. 一次性提醒
编辑时选择「一次性」，指定**日期 + 时间**，到点提醒一次，之后标记「已完成」结束，不再继续计时。

### 4. 提醒方式（可二选一或都要）
- **通知横幅**：系统通知栏弹出，5 秒自动消失或手动关闭；可单独开关**响铃、震动**
- **全屏闹钟**：**锁屏时自动弹出全屏闹钟页**，持续响铃，必须手动点「停止响铃」才会停

### 5. 其他实用功能
- **立即测试**：任务卡片上的按钮，立刻触发一次提醒表现（用于验证声音/震动/全屏效果），不影响正常调度
- **暂停 / 恢复**：任务卡片开关随时暂停或恢复，恢复后重新计时
- **编辑 / 删除**：随时修改任务内容或移除
- **任务持久化**：设置保存在手机本地，重启 App / 重启手机后任务与闹钟自动恢复
- **使用说明**：App 右上角「使用说明」按钮，可随时查看需要开启的权限与设置路径

## 二、安装与使用说明

### 1. 安装
把 `release/TimerReminder.apk` 传到手机点开安装（首次需允许"安装未知来源应用"）。支持 **Android 8.0 及以上**。

### 2. 第一次使用：先授权（关键！）
打开 App，按顶部「**需要授权**」卡片逐项处理（或点右上角「使用说明」）：

| 授权 | 作用 | 说明 |
| --- | --- | --- |
| 通知权限 | 到点弹出提醒通知 | **必开**，不开不提醒（Android 13+） |
| 电池优化白名单 | 息屏/后台不被系统延迟 | **强烈建议**，否则长时间息屏可能延迟提醒 |
| 全屏闹钟权限 | 锁屏时自动弹全屏闹钟页 | Android 14+ 需在系统设置里授予「闹钟和提醒」 |
| 后台弹出界面权限 | 后台时能直接弹出全屏闹钟页 | **国产手机（小米/华为/OPPO/vivo/荣耀）需开启**，否则后台时全屏闹钟会被拦截、只显示通知 |
| 锁屏显示权限 | 锁屏时显示全屏闹钟界面 | 不开启时锁屏可能只响铃不显示界面；需在系统设置中允许「锁屏显示」 |
| 自启动 / 后台运行 | 划掉任务后仍能收提醒 | 国产手机（小米/华为/OPPO/vivo/荣耀）需在系统设置 → 应用管理 → 定时提醒 中开启 |

### 3. 添加提醒
点右下角 **＋** 新建任务：

- **名称**：自定义，如"喝水"
- **类型**：循环提醒 / 一次性
- **间隔分钟**（循环）：1 ~ 9999 的任意整数
- **截止时间**（循环，可选）：日期 + 时间
- **提醒时间**（一次性）：日期 + 时间
- **提醒方式**：通知 / 全屏闹钟 / 两者
- **响铃、震动**：单独开关
- **启用**：保存后立即开始生效

### 4. 常见问题：到点没提醒？
按顺序排查：

1. 通知权限是否已开（App 顶部卡片或系统设置 → 通知 → 定时提醒）
2. 电池优化白名单是否已加入（系统设置 → 电池 → 应用省电策略 → 不限制）
3. 国产手机是否允许自启动 / 后台运行
4. 手机是否开启勿扰模式 / 静音
5. 长时间息屏时系统省电可能延迟提醒——加入电池白名单可基本解决

## 四、技术架构

```
┌─────────────────────────────────────────────────┐
│  UI（Jetpack Compose）                          │
│  任务列表 · 添加/编辑弹窗 · 全屏闹钟页 · 使用说明 │
└───────────────┬─────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────┐
│  调度层（AlarmManager + BroadcastReceiver）       │
│  每个任务独立闹钟（setAlarmClock，精确触发）       │
│  触发后自动排下一次 · 开机广播恢复所有闹钟        │
└───────────────┬─────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────┐
│  提醒表现层                                       │
│  通知渠道（声音/震动可配） · 全屏闹钟（前台服务）   │
│  持续响铃直到手动停止                             │
└───────────────┬─────────────────────────────────┘
                ▼
┌─────────────────────────────────────────────────┐
│  数据层（SharedPreferences + JSON）               │
│  任务模型：类型/间隔/截止/提醒方式/开关/状态       │
└─────────────────────────────────────────────────┘
```

关键设计点：

- **循环调度**：不用 `setRepeating`（不精确），而是每次触发后按「上次触发时间 + 间隔」计算下一次，用 `setAlarmClock` 精确设定——休眠/重启后依然准时
- **截止时间**：每次重排前判断是否已过截止，过期即停止
- **一次性提醒**：触发后标记「已完成」并取消后续调度
- **开机恢复**：监听 `BOOT_COMPLETED`，重启后自动重排所有启用任务
- **独立任务**：每个任务独立 `PendingIntent`（requestCode = 任务 id），互不干扰

## 六、开发与构建

**用 Android Studio 开发**：打开 `android/` 目录 → 同步 → 运行。详见 `android/README.md`。

**命令行构建**（需 Android Studio 自带 JBR）：

```bat
set JAVA_HOME=D:\Android Studio\jbr
cd android
gradlew.bat assembleRelease        :: 正式签名包（app\build\outputs\apk\release\）
gradlew.bat assembleDebug          :: 调试包
gradlew.bat testDebugUnitTest      :: 单元测试
```

## 七、版本管理

- 正式版 1.0.0 为首次提交（git tag `v1.0.0`），GitHub 同步见 `sync-to-github.sh`
- 后续改动流程：改代码 → `gradlew.bat testDebugUnitTest` 通过 → 构建 release → 更新 `CHANGELOG.md` → 提交
- **升级必须用同一把签名密钥**（`android/keystore/timereminder.jks` + `keystore.properties` 密码），否则已安装用户无法覆盖更新
