不用装任何东西。两个包里都已内置对应平台的 Node.js 运行时，解压后直接双击就能跑， 浏览器会自动打开 http://localhost:3000。
演示模式完全免费：不填任何 Key 就能完整体验任务流转；想产出真正的 MP4， 在页面顶栏「⇄ 切换通道」里粘贴你自己的 API Key 即可——Key 只存在你自己的电脑上。
macOS 首次启动如果提示「无法验证开发者」，对着 start.command 右键 → 选「打开」→ 再点「打开」，只需做一次。
