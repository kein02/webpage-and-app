> 调研时间：**2026-10-24**
> 价格与版本每月都在变，凡标注「以官网为准」的项，接入前请再确认一次。
> 币种：人民币（¥）为国内官方刊例价，美元（$）为国际刊例价，不做汇率换算。

## 0. 三分钟结论（先看这个）

| 你的情况 | 建议接入 | 理由 |
| --- | --- | --- |
| 想**零成本**先跑通流程 | 本地 `Ollama`？不行，视频要 GPU。<br>→ **fal.ai / SiliconFlow 的 Wan** | 单条 5 秒约 ¥1–2，最便宜的正经出片方案 |

## 1. 国际闭源模型（官方 API 直连）

### Google Veo 3.1
- **能力**：文生视频 / 图生视频 / 参考视频；**原生同步音频**（对白+音效）；最长 8 秒（可链式延长）；最高 4K
- **接入**：Gemini API 或 Vertex AI（`generateVideos`），异步任务；企业版可走 VPC / 区域驻留
- **价格**：分三档 —— Lite ≈ **$0.15/秒**、Fast ≈ **$0.50/秒**、Standard ≈ **$0.75/秒**（也有报 $0.05–0.60/秒区间的，按档位与地区浮动，**以官网为准**）
- **特点**：SynthID 隐形水印；音频是它最大的差异化
- **适合**：高端广告、影视预告、需要口型和音效的成品
- **文档**：ai.google.dev（Gemini API 的 video generation）

### Runway Gen-4 / Gen-4.5
- **能力**：文生 / 图生 / 视频生视频；运动笔刷、重打光、角色对话；10 秒，可升 4K
- **接入**：Runway 独立 API + SDK，**仅轮询**（无 webhook）
- **价格**：约 **$0.12/秒**（Turbo $0.25/次；老套餐 $0.50–1.00/5 秒）
- **注意**：审核失败**仍可能扣费**；默认会把数据用于训练（需在合同里 opt-out）
- **适合**：创意机构的 VFX 预演、需要"导演级"控制
- **文档**：docs.dev.runwayml.com

### Luma Ray 3 / 3.x（Dream Machine）
- **能力**：文生 / 图生 / Extend 延长（可达 30 秒）；1080p HDR、ACES 色彩、EXR 导出
- **接入**：REST + SDK；**轮询 + webhook + 失败退款**
- **价格**：约 **$0.08/秒**（Flash 档 $0.24/次）
- **特点**：电影感与物理逻辑强，商业授权按套餐给
- **文档**：docs.lumalabs.ai

### Kling 3.0 / 3.1（快手，国际版）
- **能力**：文生 / 图生 / 运动迁移；10–15 秒，最高 4K；强动作、多机位一致性、支持口型
- **接入**：官方开放平台（国际 klingai.com / 国内 klingai.kuaishou.com 分开）；聚合平台 fal、Replicate、Higgsfield 也能调
- **价格**：$0.07–0.14/秒；国内刊例约 **¥0.9/秒（720P 有声）**
- **注意**：免费档**非商用 + 带水印**
- **文档**：app.klingai.com/cn/dev/document-api

### Seedance 2.0 / 2.5（字节跳动，即梦同源）
- **能力**：文生 / 图生（最多 12 张参考）/ 音频 / 视频输入；15–20 秒，2K；**多镜头叙事 + 多语言音频**
- **接入**：两条路 —— ① **火山方舟 ModelArk**（国内官方，OpenAI 风格异步）② fal / Higgsfield（国际）
- **价格**：国内约 **¥0.99–3.74/秒**；fal 上 720p 约 **$0.30/秒**
- **特点**：图生视频口碑第一梯队；国内可用"每日 12 条"免费额度
- **文档**：volcengine.com（方舟 → 视频生成）

### Hailuo 02 / 2.3 / H3（MiniMax 海螺）
- **能力**：文生 / 图生 / S2V（主体参考）；6–15 秒，最高 2K；**立体声**；物理模拟强
- **接入**：官方开放平台（**注意双区域，Key 不互通**：国内 platform.minimaxi.com / 国际 platform.minimax.io）；fal 也可调
- **价格**：**$0.017/秒起**（目前市面上最便宜的商用 API 之一）；国内 768P ≈ **¥0.3/秒**
- **特点**：性价比之王；H3 已开源权重
- **文档**：platform.minimaxi.com/document

### Luma / Pika / Grok Imagine（补充位）
- **Pika 2.2**：**无官方 API**，只能走 fal（约 $0.20/10 秒/1080p）；1–10 秒；社媒快剪够用
- **Grok Imagine（xAI）**：文生/图生，1080p，$0.08–0.22/片；部分带音频；偏"快、casual"的社媒风格
- **Higgsfield**：不是模型厂，是聚合+特效商，能调 Kling / Seedance / Sora（Sora 已停）

## 6. 接入范式（三种，选一种就行）

### 范式 A：OpenAI 风格同步/异步 REST（最常见）
```http
POST /v1/video/generations     Authorization: Bearer <KEY>
{ "model": "...", "prompt": "...", "duration": 5, "resolution": "720p" }
→ 202 { "id": "task_xxx" }            # 立刻返回任务号
GET  /v1/video/generations/task_xxx    # 轮询，直到 status=completed
→ 200 { "status": "completed", "url": "https://.../xxx.mp4" }
```
**适用**：火山方舟 Seedance、可灵、Vidu、MiniMax、SiliconFlow、Agnes

### 范式 B：云厂商 SDK（要发票/合规就走这条）
```python
# 阿里云百炼 DashScope
from dashscope import VideoSynthesis
r = VideoSynthesis.call(model="wanx2.1-t2v-turbo", prompt="...", size="1280*720")
# 腾讯云 / 火山方舟同理，各自 SDK + AK/SK 签名
```

### 范式 C：聚合平台统一入口（fal 为例）
```js
const r = await fetch("https://fal.run/fal-ai/kling-video/v3/pro/text-to-video", {
  method: "POST",
  headers: { Authorization: "Key " + process.env.FAL_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({ prompt: "...", duration: "5" })
});
// 返回 video.url，无需自己轮询任务状态
```

### 三个工程细节，不注意会踩
1. **webhook 支持不一致**：Luma / Hailuo / Vidu / Seedance 支持回调；**Runway、混元只支持轮询**——不要按同一种方式写。
2. **区域 Key 不互通**：MiniMax 国内站与国际站是两套账号；Agnes 也是（`platform.agnes-ai.cn` 的 Key 必须配 `api.agnes-ai.cn`，用 `apihub.agnes-ai.com` 会 401）。
3. **失败可能照样扣费**：Runway 审核失败仍计费；Vidu 明确"失败不计费"。批量跑之前先确认这条。

## 8. 给这个项目（DreamForge）的接入建议

### 先说结论：三档方案，零成本起步

| 档位 | 接什么 | 成本 | 补什么能力缺口 |
| --- | --- | --- | --- |
| **① 零成本（首选）** | **智谱 CogVideoX-Flash** | **官方定价页标 0 元**，不占用新用户赠送 Token | 高清 + 更长时长（现有 Agnes 只有 720P/4–12 秒）；OpenAI 兼容接口，改动最小 |
| **② 极便宜** | **硅基流动 SiliconFlow 的 Wan 2.2** | 约 ¥1–2/条（5 秒），注册送额度，支付宝充值 | 便宜的备用通道；Wan I2V 可补图生视频 |
| **③ 能力补充** | **MiniMax 海螺 H3** | 国内 ¥0.3/秒（768P）、国际 $0.017/秒起 | **原生音频** + 主体参考（S2V）；现有通道全是静音 |
| ④ 合规交付（后续） | 火山方舟 Seedance 2.0 | ¥0.99/秒，新用户每模型 50 万 Tokens | 国内发票、4K、多镜头叙事 |

### 为什么把智谱排在第一位

1. **官方定价页直接写「免费」**（CogVideoX-Flash），且不消耗赠送的 2000 万 Token——额度独立，忘了关也不会扣钱；
2. **手机号注册、无需信用卡、国内直连**，门槛最低；
3. **接口兼容 OpenAI 格式**，本项目 provider 层几乎可以原样套用；
4. 宣传口径是 4K/60fps、最长 10 秒（实测以官方为准），比 Agnes 的 720P/4–12 秒强一档。

> 注意：免费档通常有并发限制（社区反馈 CogVideoX-Flash 并发约 3），不适合当"公开部署的主力通道"，适合作为**本地/个人使用的高清选项**。

### 明确不要碰的

- ❌ **第三方 API 中转站**（那种"1 元 285 万 Token"的）：2026 年 5 月已有站长因非法获取 API 被刑事拘留的判例；安全团队抽测 428 个中转站，9 款注入恶意代码、17 款试图窃取云凭证。省下的钱远不够赔。
- ❌ **把公开部署的主力 Key 换成免费档**：免费额度会限流，访客一多就全挂。公开部署仍建议"访客自带 Key"。

### 落地改动量（本项目实测）

加一个 provider 只需三步，约 30–60 行代码：

1. `models.config.json` 的 `providers` 加一段（base_url / 鉴权 / 模型名映射 / 参数翻译规则）
2. `server.js` 的 `buildUpstreamBody` 加一个分支（把统一的参数翻译成对方格式）
3. `submitUpstream` + `pollProviderTasks` 各加一个分支（提交、轮询或回调）

**推荐实施顺序**：智谱（免费，先跑通）→ MiniMax（补音频/图生视频）→ 硅基流动（便宜兜底）→ 火山方舟（商用交付）。
