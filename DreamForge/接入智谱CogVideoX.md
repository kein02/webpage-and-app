# 接入智谱 CogVideoX（0 元通道）

**为什么推荐这条**：`cogvideox-flash` 在智谱官方定价页上的单价就是 **0 元**，而且**不占用**新用户赠送的 2000 万 Token（额度独立，忘了关也不会扣钱）。手机号注册、不需要信用卡、国内直连。

---

## 一、拿 Key（约 2 分钟）

1. 打开 [open.bigmodel.cn](https://open.bigmodel.cn)，用**手机号**注册并登录；
2. 左侧菜单点 **API Keys**（有的版本叫「密钥管理」）；
3. 点**新建**，名字随便填（比如 `dreamforge`）；
4. 复制生成的 Key —— 格式是一长串 `xxxxxxxx.yyyyyyyy`（中间有个点，**整段都要**）。

> ⚠️ 这个 Key 只显示一次，关掉页面就看不到了；丢了就重新建一个。

## 二、填进项目

把 Key 写进项目根目录的 `.env`：

```
ZHIPU_API_KEY=你的完整Key
```

保存后**重启服务**（`Ctrl+C` 再双击 `start.bat`），或者直接在页面「⇄ 切换通道」里点「智谱 CogVideoX」粘贴 Key 保存——后者立即生效、不用重启。

## 三、验证成功的样子

启动日志里会出现：

```
出片模式:     真实出片 · 智谱 CogVideoX（免费）
```

页面顶栏徽章变成「🔥 真实出片 · 智谱（免费）」。

## 四、和另外两个通道的区别

| | 智谱 CogVideoX（免费） | Agnes（免费） | 火山方舟（付费） |
| --- | --- | --- | --- |
| 费用 | **0 元** | 限时免费 | 按量付费 |
| 分辨率 | 720P / 1080P | 720P | 最高 1080P/4K |
| 时长 | 5–10 秒 | 4–12 秒 | 4–30 秒 |
| 水印 | **有**（官方免费档行为） | 无 | 无 |
| 首帧图 | ❌ 不支持本地图 | ❌ | ✅ |
| 出片速度 | 约 60 秒 | 约 30–60 秒 | 视模型 |

## 五、必须知道的三个坑

1. **成片带水印**。免费档返回的文件名是 `xxx_watermark.mp4`，这是官方行为，不是程序 bug。
2. **高峰期会排队**。实测白天提交 4 次有 3 次返回 `1305（访问量过大）`。项目已经做了处理：
   - 先在同一轮里自动重试 2 次；
   - 还排不上就把任务**退回队列**（状态显示「排队中 ×N」），按 30s → 60s → 120s 递退避重试，最多 10 次（约 20 分钟）；
   - 全程可以随时点「取消」。
3. **不要拿它当公开部署的主力通道**。免费档有并发限制（社区反馈约 3），访客一多全在排队。公开部署请保持「访客自带 Key」。

## 六、免费额度的边界（别踩）

- 免费的是 `cogvideox-flash` 这个**模型**，但平台仍会有并发/频率限制，不代表无限用；
- 想升级画质可以切 `cogvideox-2`（约 ¥0.5/次）或 `cogvideox-3`（按官网价），在 `models.config.json` 里把 `upstream_model` 改掉即可；
- 免费政策随时可能变（Sora 就是一年内直接关停的例子），所以项目保留了三档通道，任何一档挂了都能切。
