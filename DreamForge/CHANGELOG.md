**新增三档出片通道（从 1 个真实通道扩到 4 个）**

| 通道 | 模型 | 成本 | 关键能力 |
| --- | --- | --- | --- |
| 智谱 CogVideoX | `cogvideox-flash` | **0 元**（不占赠送额度） | 720P/1080P、5–10 秒；成片带水印 |

| MiniMax 海螺 | `MiniMax-Hailuo-2.3-Fast` | 约 ¥0.3/秒 | 原生音频；`file_id → /v1/files/retrieve` 两步取片 |

**新机制：上游排队退回队列**

智谱免费档在白天高峰会用 HTTP 200 + 业务码 `1305` 表示"访问量过大"（不是 429，按状态码重试抓不到）。实测 4 次提交有 3 次被拒，原来的"34 秒内重试 5 次"会让任务直接失败。

改为：单轮只重试 2 次（约 9 秒）→ 仍失败则**把任务退回队列**（`retry_at` 退避 30s → 60s → 120s，上限 10 次约 20 分钟），前端显示「排队中 ×N」，用户可随时取消。排队不再是失败。

**通道自动选择顺序**

`agnes → zhipu → siliconflow → minimax → volcengine`（有 Key 的第一个生效；都没配则回退演示模式）

**修复：硅基流动轮询用错 HTTP 方法（会导致该通道必失败）**

`/v1/video/status` 只接受 **POST**（body `{requestId}`）。原先写成 GET + query 参数，
真实接口一律返回 404，用户配了 Key 也会看到「上游创建失败」。

用假 Key 探测真实端点确认的（2026-10-24）：

| 端点 | 假 Key 响应 | 结论 |
| --- | --- | --- |
| `POST /v1/video/submit` | 401 `Token is invalid` | 路径正确 |
| `GET  /v1/video/status?...` | 404 Not Found | ❌ 路径错 |
| `POST /v1/video/status` | 401 | ✅ 正确（POST） |
| MiniMax `/v1/video_generation` | 200 + `base_resp 1004` | 路径正确 |
| MiniMax `/v1/query/video_generation`、`/v1/files/retrieve` | 200 + `1004` | 路径正确 |

同时把本地假上游改成按真实行为响应（`GET /video/status` 返回 404、状态按
InQueue→InProgress→Succeed 推进），并复测两档全链路通过。

**修复：安全测试误报**

`.env` 的断言改成只针对 `.env.example`（唯一进仓库/进包的那份）；开发者本机 `.env`
放真实 Key 是正常用法，原先会让开发机上 `npm test` 永远红一条。

## v1.0.0 — 2026-10-24

首个公开版本。

**核心**
- 复刻即梦AI 创作台架构：服务端下发模型注册表、提交-轮询任务流、草稿样片→直出高清、独立提示词润色服务、页面内一键切换出片通道。
- 零第三方依赖、零构建步骤：`node server.js` 直接跑。
- 三种出片模式：演示（程序化 SVG，零花费）/ Agnes AI 免费通道（真 MP4）/ 火山方舟 Seedance（真 MP4 + 首帧图 + 草稿样片）。

**部署与分享**
- 便携版打包脚本：把 Node 运行时打进 zip，对方零安装双击即用；内置 Key 安全闸（检测到 `.env` 有 Key 就拒绝打包）。
- 公网部署：提供通用部署指引（Zeabur / Render / Koyeb 等任意支持长驻 Node 的平台；demo 兜底 + 公开部署锁）。
- 访客自带 Key：Key 只存访客浏览器、请求头透传、服务端零持久化，出片走各自额度。

**安全**
- 任务按浏览器隔离，跨访客操作一律 404。
- 提交闸门：每访客在途上限 2、全局上限 60、无 clientId 拒绝建任务（实测 80 并发不崩）。
- 统一安全响应头（CSP / XCTO / XFO / Referrer-Policy / Permissions-Policy / HSTS）。
- 参数白名单化 + `safeStr`/`safeNum` 类型收敛，畸形输入不再产生 5xx。
- Agnes 接口地址白名单，防 SSRF；目录穿越防护；16MB 请求体上限。

**测试**
- `npm test`：5 套 115 项断言（本地回归 / 安全 / 访客 Key 隔离 / 任务隔离 / 前端公开模式）。
- 渗透测试 17 项（响应头、方法矩阵、Host 注入、原型污染、类型混淆、越权矩阵、状态机、并发、存储型 XSS）。
