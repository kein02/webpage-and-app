# 部署到公网（可选）

> 这个项目**不需要联网部署也能用**——下载便携包双击就跑（见 [README](README.md)）。
> 这份文档是给「想让所有人点开一个链接就能用」的场景准备的。

目标：把项目变成一个 `https://xxx.xxx.com` 的公开链接，任何人打开即用，不用装任何东西。

## 先明确一件事

**GitHub Pages / Netlify / Vercel / Cloudflare Workers 都不行**——它们只能跑静态网页或"请求来了才执行"的函数，没有常驻进程。本项目的任务队列靠定时器持续推进状态机，必须有长驻的 Node 进程。

能用的只有：**Render / Zeabur / Koyeb / Railway / Fly.io / 自己的服务器**。

## 你需要填的配置只有三项

不管用哪个平台，都是这三样（本仓库**不再内置任何平台配置文件**，按下面手动填）：

| 项目 | 值 |
| --- | --- |
| 根目录 / Root Directory | `DreamForge` |
| 启动命令 / Start Command | `node server.js` |
| 环境变量 | `DREAMFORGE_PROVIDER=demo`<br>`DREAMFORGE_PUBLIC=1` |

> 端口不用管：平台会注入 `PORT`，代码已经读这个变量。
> 构建命令可以留空或 `npm install`（本项目零依赖，装不装都一样快）。

---

## 路线 A：Zeabur（中文界面、免信用卡，**推荐**）

1. [zeabur.com](https://zeabur.com) → 用 **GitHub 登录**（免费档不需要绑卡）；
2. **New Project** → 区域选 **Hong Kong** 或 **Singapore**；
3. **Add Service** → **Git** → 选你的 `webpage-and-app` 仓库；
4. 按上面三项填写（**根目录一定要填 `DreamForge`**，否则找不到 `package.json`）；
5. 部署，等 1–2 分钟，得到 `https://xxx.zeabur.app`。

免费档：无流量时会自动休眠，下一个访客需等几秒唤醒。

## 路线 B：Render

1. [dashboard.render.com](https://dashboard.render.com) → GitHub 登录；
2. **New +** → **Web Service**（不是 Blueprint，本仓库不再提供 blueprint 文件）→ 选仓库；
3. 填：Root Directory `DreamForge`、Runtime `Node`、Build Command `npm install`、Start Command `node server.js`；
4. **Environment** 里加两个环境变量（见上表）；
5. Plan 选 Free → Create，等日志出现「◆ DreamForge 造梦工坊 已启动」；
6. 得到 `https://xxx.onrender.com`。

> Render 免费档 15 分钟无访问会休眠，**下一个访客要等 30–60 秒**才加载出来；部分地区注册需要信用卡，卡住就换路线 A。
> 免费实例的磁盘是临时的，重启后 `public/videos/` 里的视频会丢（演示模式不受影响，结果在内存里）。

## 路线 C：Koyeb / Railway / 自己的服务器

逻辑完全一样：能跑 `node server.js`、能读 `PORT`、能设环境变量就行。

- Koyeb：免费档需要信用卡做验证（不扣费）
- Railway：免费额度约 $5/月，需绑卡
- 自己的服务器：`nohup node server.js &` 或写成 systemd 服务，前面挂 Nginx 反代

---

## 部署完成后要验证的三件事

1. 用**手机流量**（不要连家里 WiFi）打开链接——能打开才算真的公网可用；
2. 页面顶栏显示「**演示模式**」徽章；
3. 随便输一句提示词点生成，能出 SVG 动画。

## 把链接放到 GitHub 主页

仓库页 → 右侧 **About** 齿轮 → **Website** 填你的域名 → Save。

## 以后改了代码怎么更新

- Zeabur / Render / Railway：默认**自动部署**，往 GitHub 推代码就会自动重新发布；
- 想关掉：各平台服务设置里把 Auto-Deploy 改成 No。

## 常见问题

**Q: 打开要等很久（30 秒以上）？**
A: 免费档休眠。第一个访客触发唤醒，之后就快了。想彻底避免得付费（Render Starter $7/月、Zeabur Dev $5/月）。

**Q: 页面 502 / Application failed to start？**
A: 九成是**根目录没填 `DreamForge`**——平台在仓库根找不到 `server.js`。其次看日志最后几行。

**Q: 访客能出真视频吗？**
A: 能，但要他自己在页面「⇄ 切换通道」里填**他自己的** Key。服务器不存任何人的 Key，不会消耗你的额度。

**Q: 一定要公网部署吗？**
A: 不需要。便携包（[Releases](https://github.com/kein02/webpage-and-app/releases/latest) 里的 zip）解压双击就能用，本地跑不花钱、不受平台限制。公网部署只是「别人不用下载」的便利。

**Q: 部署后和本地跑有什么区别？**
A: 唯一区别是 `DREAMFORGE_PUBLIC=1` 生效后：服务器不存任何人的 Key、任务按访客浏览器隔离、每访客限 2 个在途任务（防刷）、全局上限 60。
