# 部署到公开链接（Render · 从 GitHub 仓库一键上线）

目标：把你的 GitHub 仓库变成 `https://xxx.onrender.com` 这样的**公开链接**，任何人点开就能用，不需要 sharecode、不需要装任何东西。

> 为什么不能用 GitHub Pages？Pages 只能放静态网页，本项目要跑 Node.js 服务端（任务队列、接口、出片流程），所以需要一个能跑 Node 进程的平台。Render 的免费档就够用，而且**项目代码一行都不用改**。

---

## 一、先决条件

- 一个 GitHub 账号，仓库已上传（本项目根目录的 `render.yaml` 就是给 Render 读的配置，已经写好）
- 一个 Render 账号：[render.com](https://render.com) → 右上角 **Get Started** → 选 **GitHub** 登录（不用填卡号）

> 免费档限制（先知道，免得上线后怀疑出错）：
> - 15 分钟没人访问会休眠，**下一个人打开要等 30–60 秒**才加载出来，之后恢复正常；
> - 每月 750 小时运行额度，单个服务够用；
> - 磁盘是临时的，服务重启后 `public/videos/` 里的视频文件会丢（演示模式不受影响，因为结果是内存里的 SVG）。

---

## 二、部署（5 步，约 3 分钟）

### 第 1 步：进 Render 控制台

打开 [dashboard.render.com](https://dashboard.render.com)，用 GitHub 账号登录。

### 第 2 步：新建 Blueprint

右上角 **New +** → 选 **Blueprint**。

### 第 3 步：连接仓库

列表里找到你的 `dreamforge` 仓库 → 点 **Connect**。
（第一次会要求授权，点 **Configure account** → 勾选这个仓库 → **Save**。如果列表里看不到仓库，先点 **Configure account** 授权。）

### 第 4 步：确认配置，点 Apply

页面会自动读出仓库里的 `render.yaml`，显示：

```
Service name: dreamforge
Runtime:      Node
Plan:         Free
Region:       Singapore
Start command: node server.js
Env vars:     DREAMFORGE_PROVIDER=demo · DREAMFORGE_PUBLIC=1 · NODE_VERSION=22
```

**看到这些说明配置被正确识别了** → 点 **Apply**（或 **Create**）。

> 想改部署地区：把 `render.yaml` 里的 `region` 改成 `oregon`（美国）或 `frankfurt`（欧洲），国内访问 Singapore 通常最快。

### 第 5 步：等它变绿

页面会跳到服务详情，日志里依次出现（约 1–3 分钟）：

```
==> Running 'node server.js'
  ◆ DreamForge 造梦工坊 已启动
  出片模式:     演示模式（已强制指定演示模式）
  在浏览器打开:  http://localhost:10000
```

**看到「◆ DreamForge 造梦工坊 已启动」就是成功了。**

页面顶部会出现你的公开地址，形如：

```
https://dreamforge-xxxx.onrender.com
```

**这就是你要的公开链接** —— 没有任何参数，发给谁都能打开。

---

## 三、验证（30 秒）

1. 复制那个 `onrender.com` 地址，用**手机流量**（不要连家里 WiFi）打开——能打开说明真的公网可用；
2. 页面顶栏应该显示「**演示模式**」灰色徽章；
3. 随便输入一句提示词点生成，能跑出 SVG 动画就算全通。

---

## 四、把链接放到 GitHub 主页

1. 打开你的仓库页面 → 右侧 **About** 齿轮 → **Website** 填 `https://dreamforge-xxxx.onrender.com` → Save；
2. 顺手把仓库右上角的 **Description** 写成一句话，比如：`一个能读懂的 AI 视频生成工作台 · 在线体验：https://...`；
3. README 顶部那个 Deploy 按钮里的 `你的GitHub用户名` 记得换成你的真实用户名。

---

## 五、以后改了代码怎么更新

Render 默认**自动部署**：只要往 GitHub 仓库 `git push`，Render 检测到新提交会自动重新构建发布（几十秒）。不需要再操作控制台。

如果不想要自动部署：服务详情 → **Settings** → **Auto-Deploy** 改成 No。

## 六、常见问题

**Q: 打开要等很久（30 秒以上）？**
A: 免费档休眠。第一个访客会触发唤醒，之后就快了。想彻底避免：升级到 Starter（$7/月）不睡眠，或用一个定时任务每 10 分钟访问一次（不推荐，容易被判滥用）。

**Q: 页面显示 502 / Application failed to start？**
A: 看 Render 日志里最后几行。常见原因：仓库里缺 `server.js`、或者 `render.yaml` 被改坏了。日志里出现「DreamForge 造梦工坊 已启动」才算正常。

**Q: 访客能用真视频吗？**
A: 能，但要他自己在页面「⇄ 切换通道」里填**他自己的** Agnes Key。服务器不存任何人的 Key，所以不会消耗你的额度。

**Q: 免费额度用完了？**
A: Render 免费是 750 小时/月，单服务常驻约 730 小时，基本够。若不够，可换 Railway / Fly.io，配置同理（都是 `startCommand: node server.js` + 三个环境变量）。

**Q: 一定要用 Render 吗？**
A: 任何能跑长驻 Node 进程的平台都行（Railway、Fly.io、Zeabur、自己的服务器）。关键是三点：`node server.js` 启动、读 `PORT` 环境变量、`DREAMFORGE_PROVIDER=demo` + `DREAMFORGE_PUBLIC=1`。**唯一不要选的是 GitHub Pages / 纯静态托管**，它跑不了后端。
