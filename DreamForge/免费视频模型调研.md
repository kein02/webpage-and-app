## 二、路线一：Agnes AI 视频 API（首推 · 限时免费）

### 2.1 它是什么

一家 2026 年新出现的 AI 公司，自研模型走 **OpenAI 兼容风格 + 异步任务制**（先创建任务拿 `video_id`，再轮询结果——这是重点：DreamForge 已有的「提交→轮询」框架可以直接套用，接入成本几乎为零）。

⚠️ **重要变更**：早期（2026 年中）主推的 `agnes-video-v2.0`（原生音画同步）**已于 2026-09-25 正式下线**，其 GitHub 仓库文档停留在 7 月已过时，别按旧教程接。现行模型系列（截至 2026-10 官网文档）：

| 模型 | 能干什么 | 价格（2026-10 口径） |
|---|---|---|
| `agnes-video-2.5-flash` | 文生视频 / 图生视频 / 参考生视频，**限时免费** | **$0/秒**（原价 $0.025/秒，随时可能恢复收费） |
| `agnes-video-2.5` | 同上，付费档 | 720P $0.025/s · 1080P/1K $0.04/s · 2K $0.055/s |

### 2.2 免费政策（官网 API 文档口径，截至 2026-10）

- ✅ **限时免费 $0/秒**：免费额度按「速度」限制而非总量——视频 **1 RPM**（每分钟最多提交 1 条），没有「每天多少秒」的总量上限
- ✅ **只需邮箱注册**：不要信用卡、不要实名认证、不要充值
- ✅ **输出无水印**
- ⚠️ 「限时」二字是官方的原话：**恢复收费的时间以官网公告为准**，别把唯一生产流程押上
- ⚠️ 高峰期免费池容量有限，可能返回 **HTTP 503（video queue is full）**——官方建议指数退避重试，DreamForge 已内置（5s/15s/30s 共 3 次）

### 2.3 能做出什么样的视频

- **时长**：`seconds` 传字符串 "4"–"12"（**注意：必须是字符串，传数字会 400**）；免费 flash 档上限 12 秒
- **分辨率**：免费 flash 档只支持 **720P**（传 1080p 也会被收敛到 720P）；1080P / 2K 是付费 `agnes-video-2.5` 档
- **声音**：旧 v2.0 的音画同步能力随模型下线一起没了；现行 2.5 系列以画面为主
- **图生视频**：`keyframe` 模式用 `first_frame` / `last_frame`、`reference` 模式用 `images[]`——**只收公网 URL，本地图片不能直接传**，必须先传到公网图床拿网址；DreamForge 的接入策略是免费通道直接不支持本地首帧图（上传就友好拒绝并提示切火山方舟通道）

### 2.4 限制与注意事项

| 项目 | 说明 |
|---|---|
| 速度 | 1 RPM = 每分钟 1 条。想批量出片不行，个人玩够用 |
| 请求体 | 明确**不收** width / height / num_frames / fps / steps / quality，传了直接 400 |
| 状态机 | queued → in_progress → completed / failed；轮询 URL 必须带 `model_name` 参数 |
| 提示词 | **英文提示词效果明显比中文稳**，建议直接用英文写（DreamForge 未内置自动翻译） |
| 长视频 | 免费档 12 秒是硬上限，做不了长片 |
| 公司风险 | 2026 年新公司，「限时免费」是获客策略，**未来可能恢复收费或调整限流** |

### 2.5 接入 DreamForge 的难度：⭐（低）—— 已完成 ✅

OpenAI 兼容 + 异步任务契约，与火山方舟 provider 同一模式。实际接入内容（2026-10-22 完成）：

- `models.config.json` 新增 `providers.agnes` 段：4 个产品模型全部映射到 `agnes-video-2.5-flash`；时长 >12s 自动截到 12、1080p 自动降到 720P，收敛后参数回写任务卡显示
- `server.js` 双通道：`auto` 模式优先检测 `AGNES_API_KEY`，`DREAMFORGE_PROVIDER` 可强制指定
- 免费通道 `max_parallel: 1` 串行提交（对应 1 RPM）
- 429 / 5xx 指数退避重试 3 次（按官方文档建议）
- 自测 47/47 通过（假上游全链路、参数收敛、401/429/503 路径、provider 矩阵、demo 回归）+ 无头浏览器截图验证
- ⚠️ 真实出片尚未跑通一次：免费池持续 503 队列繁忙（curl 直连官方同款请求体同样 503，非代码问题），队列缓解后提交即可
