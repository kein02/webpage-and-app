# 接入真实模型：让 DreamForge 产出真正的视频

本指南面向**不懂编程**的用户：每一步都说明在哪个窗口操作、点什么、看到什么算成功。
全程约 20–30 分钟，需要花一点钱（视频模型开通条件：账户余额 ≥ 200 元）。

> 不想花钱？跳过本指南，保持演示模式也能完整体验任务流转（只是不出真片）。

---

## 第 1 步：注册火山方舟账号

1. 浏览器打开 **https://console.volcengine.com**（火山方舟控制台，字节跳动旗下，即梦同款模型的服务端）。
2. 点右上角「注册」，用手机号注册并完成验证码。
3. **成功标志**：能进入控制台首页，左上角显示你的账号名。

## 第 2 步：实名认证（不实名不能充值）

1. 控制台右上角头像 → 「账号中心」→ 「实名认证」。
2. 个人用户选「个人认证」：填姓名 + 身份证号，按提示刷脸或支付宝授权；企业用户选企业认证（营业执照）。
3. **成功标志**：认证状态显示「已实名认证」。

## 第 3 步：充值（至少 200 元）

1. 控制台右上角「充值」或左侧「费用中心 → 充值」。
2. 选「在线支付」，充 200 元或以上（视频模型的开通条件就是余额 > 200 元；也可购买 200 元档「节省计划」更划算）。
3. **成功标志**：「费用中心 → 账户总览」里可用余额 ≥ 200 元。

## 第 4 步：开通视频模型

1. 左侧菜单「模型广场」→ 搜索 **Seedance**（或「视频生成」）。
2. 找到 **Doubao-Seedance-2.5**（本工具主力模型）和 **Doubao-Seedance-1.0-pro**（快速便宜档），分别点「开通」。
3. **成功标志**：模型详情页按钮变成「已开通 / 去调用」。

## 第 5 步：创建 API Key（密钥）

1. 左侧菜单「API Key 管理」→「创建 API Key」。
2. 名称随意（如 `dreamforge`），点确认。
3. **关键**：创建成功后密钥**只完整显示这一次**，马上复制保存到记事本。弄丢了就删掉重建一个，不影响其他。
4. **成功标志**：密钥列表里有一条你刚创建的记录（形如 `xxxx-xxxx-xxxx` 的一长串）。

## 第 6 步：把密钥写进 DreamForge

1. 用**记事本**打开 `dreamforge\.env` 文件（在本指南所在目录的上一级就是 `dreamforge` 文件夹）。
2. 找到 `VOLC_API_KEY=` 这一行，在等号后面粘贴你的密钥（不要加引号、不要留空格）：
   ```
   VOLC_API_KEY=这里粘贴你的密钥
   ```
3. `Ctrl + S` 保存，关闭记事本。

## 第 7 步：重启服务

1. 回到运行服务的黑窗口（有 `◆ DreamForge 造梦工坊 已启动` 字样的那个）。
2. 按 `Ctrl + C` 停掉，重新双击 `start.bat`（或再跑一次 `node server.js`）。
3. **成功标志**：启动信息里显示 `出片模式: 真实出片 · 火山方舟 Seedance`；浏览器页面顶栏出现橙色徽章 **🔥 真实出片**。

## 第 8 步：花小钱验证一次

1. 页面左侧选 **ForgeVideo 2.0 Pro**，提示词写「一只橘猫在窗台上晒太阳，微风吹动窗帘」，时长选 **5 秒**，分辨率 **720p**，点「🚀 开始生成」。
2. 这次真实花费约 **7.6 元**（480p 约 3.4 元更便宜）。任务卡会显示「上游 xxx」任务 ID，状态走到「已完成」后就能**直接播放视频**，作品库可下载 MP4。
3. **成功标志**：看到能播放的视频，且「费用中心 → 账单」里能看到对应扣费。

## 真实花费速查（估算，以账单为准）

| 本工具的模型 | 上游模型 | 典型花费 |
| --- | --- | --- |
| ForgeVideo 1.0 Fast | Seedance 1.0 pro | 3 秒 480p ≈ 1.4 元；5 秒 720p ≈ 5 元 |
| ForgeVideo 2.0 Pro | Seedance 2.5 | 5 秒 720p ≈ 7.6 元；10 秒 ≈ 15 元 |
| ForgeVideo 2.5 样片模式 | Seedance 2.5 | 样片 5 秒 480p ≈ 3.4 元；满意后直出 1080p ≈ 15 元+ |
| ForgeCine 电影版 | Seedance 2.5 | 8 秒 1080p ≈ 24 元；15 秒 ≈ 45 元 |

计费规则（上游官方）：**只对成功生成的视频计费**；生成失败不收费——失败不会给你带来任何花费。

## 真实模式与演示模式的差异

| 行为 | 演示模式 | 真实模式 |
| --- | --- | --- |
| 产出 | SVG 动画 | 真实 MP4 视频 |
| 速度 | 几秒~十几秒（模拟） | 几十秒到几分钟（上游排队，正常现象） |
| 中途加速按钮 | 有 | 无（速度由上游队列决定） |
| 生成失败 | 不会发生 | 会（上游排队/限流/审核），任务卡显示失败原因，不收费 |
| 首帧图 | 只传文件名 | 真实上传图片内容 |
| 草稿模式 | 模拟 | 走 Seedance 2.5 原生 draft 样片能力 |

## 出问题时先查这里

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 顶栏显示「演示模式（未配置 Key）」 | .env 里密钥没保存好或没重启 | 检查 `.env` 里 `VOLC_API_KEY=` 等号后确实粘贴了密钥；保存后重启服务。**更省事的方式**：页面顶栏点「⇄ 切换通道 → 通道配置」，把 Key 粘进去点「保存并切换到火山方舟」，立即生效不用重启 |
| 任务失败：「API Key 无效或未授权（401）」 | 密钥复制错了或带了空格/引号 | 重新去控制台复制，注意只粘贴密钥本身 |
| 任务失败：「模型未开通或不存在（404）」 | 第 4 步漏了某个模型 | 回控制台模型广场，把 Seedance 2.5 和 1.0 pro 都开通 |
| 任务失败：「余额不足」类提示 | 账户钱不够 | 去「费用中心」充值 |
| 任务一直「上游处理中」好几分钟 | 上游排队，正常 | 等待；官方说明高峰期可能较久 |
| 提示词被拒绝、任务失败 | 上游内容审核不通过 | 换措辞重试；失败不收费 |
| 任务卡显示「上游 cgt-xxxx」 | 这是上游任务 ID | 向别人求助时把它一起提供，便于排查 |

## 安全提醒

- `.env` 里是你的真实密钥，**不要把这个文件发给任何人**或截图到网上。
- 密钥泄露时：控制台「API Key 管理」→ 找到那条 →「禁用/删除」，然后重新建一个。
