# 接入 Agnes AI（免费出片通道）—— 一步一步来

> 适合人群：完全不懂编程，只会用鼠标和记事本。
> 目标：让 DreamForge 顶栏显示 **🔥 真实出片 · Agnes AI**，能生成真正的 MP4 视频。
> 全程约 10 分钟（主要是注册账号 + 等邮件）。

> ⚠️ **国内版 / 国际版是两个体系（2026-10-23 实测确认）**：
> - 国内站：https://platform.agnes-ai.cn （注册、创建 Key）↔ 接口 **https://api.agnes-ai.cn**
> - 国际站：https://platform.agnes-ai.com ↔ 接口 https://apihub.agnes-ai.com
> - **Key 与接口分区域绑定**：国内站创建的 Key 必须配 `api.agnes-ai.cn`，国际站的 Key 必须配 `apihub.agnes-ai.com`，混用必报 401
> - ⚠️ 别被 `apihub.agnes-ai.cn` 误导——那个域名是在线的，但**不是**国内站的官方接口，拿国内 Key 打它会 401（2026-10-23 实测踩坑）
> - 本机当前已按国内版配置：系统环境变量 `AGNES_API_ROOT=https://api.agnes-ai.cn`，**Key 必须在国内站创建**

---

## 第 0 步：先搞清楚「免费」的含义（30 秒）

Agnes AI 现在有一个免费通道，模型叫 `agnes-video-2.5-flash`：

| 项目 | 免费通道（现在接的这个） |
|---|---|
| 花多少钱 | **限时免费，$0/秒**（官方原价 $0.025/秒，随时可能恢复收费，以官网公告为准） |
| 清晰度 | 只支持 720P |
| 时长 | 4–12 秒（超出会被自动截短） |
| 速度 | 每分钟最多提交 1 条 |
| 水印 | 无 |
| 能力 | **只支持文生视频**（写提示词出片）；不支持传本地首帧图 |
| 排队 | 高峰期可能遇到「队列繁忙」，程序会自动重试 3 次（等 5 秒 / 15 秒 / 30 秒） |

更高清（1080P / 2K）或更长时长是同一个公司的付费模型，本文不涉及。
想要首帧图（图生视频）→ 走火山方舟通道，见《接入真实模型.md》。

---

## 第 1 步：注册 Agnes AI 账号（国内站）

1. 浏览器打开 **https://platform.agnes-ai.cn**（注意是 .cn 国内站；.com 是国际站，两边账号不通用、Key 不通用）
2. 点注册（Sign Up），按页面提示注册（国内站一般支持手机号或邮箱）
3. 完成验证，登录进控制台。

---

## 第 2 步：创建 API Key

1. 登录后，在网站里找到 **API Keys**（或「密钥管理」）页面。
2. 点 **Create Key / 创建密钥**，随便起个名字，比如 `dreamforge`。
3. 创建成功后，会显示一串以 `sk-` 开头的字符（约 51 位），**形如**：
   `sk-示例Key请替换成你自己的-000000000000000000000000000000000000000000`
   （上面这串是假占位符。⚠️ 千万不要把真实 Key 写进任何文档、截图或聊天记录——文档是会分享的。）
4. **立刻复制它**（复制按钮，或手动选中按 Ctrl+C），先粘贴到记事本里存着。
   ⚠️ 这个 Key 只显示一次，关掉页面就看不到了，忘了就只能删掉重建。

---

## 第 3 步：把 Key 写进 DreamForge 的 .env 文件

1. 打开你放置 DreamForge 的文件夹（例如 `D:\dreamforge`，以你实际解压/克隆的位置为准）
2. 找到文件 **`.env`**（就是那个没有名字、后缀是 env 的文件）。
   - 如果看不到它：在文件夹顶部点「查看」→ 勾选「文件扩展名」和「隐藏的项目」。
3. **右键点击 `.env` → 打开方式 → 记事本**。
4. 找到这一行：
   ```
   AGNES_API_KEY=
   ```
5. 在等号**后面**粘贴你的 Key（等号前后都不要加空格、不要加引号），像这样：
   ```
   AGNES_API_KEY=sk-这里粘贴你的真实Key
   ```
6. `Ctrl + S` 保存，关掉记事本。

> ⚠️ **重要提醒（这台电脑已经踩过坑）**：
> 你的 Windows **系统环境变量**里已经有一个 `AGNES_API_KEY`（之前注册 Agnes 时配的）。
> **系统环境变量优先于 .env 文件**——也就是说：
> - 如果你现在不填 .env，程序也会自动用系统里那个 Key，一样能跑；
> - 但如果你以后**换了一个新 Key**，只改 .env 是不生效的，还得去改系统环境变量（改法见本文最后的「常见问题」第 2 条）。

---

## 第 4 步：重启 DreamForge

1. 如果 DreamForge 窗口（黑色命令行窗口）还开着：点一下它，按 `Ctrl + C` 停掉，关掉窗口。
2. 双击 `start.bat`（或在 PowerShell 里 `node server.js`）。
3. 看黑色窗口里打出来的字，**成功的样子**是这样：

```
  ◆ DreamForge 造梦工坊 已启动
  出片模式:     真实出片 · Agnes AI（免费通道）
  免费通道:     agnes-video-2.5-flash · 720P · 4–12 秒 · 每分钟 1 条（限时免费，以官网公告为准）
  注意:        该通道暂只支持文生视频；首帧图请配置 VOLC_API_KEY 用火山方舟通道
  在浏览器打开:  http://localhost:3000
```

如果写的是 `出片模式: 演示模式`，说明 Key 没读到——回第 3 步检查，或看文末「常见问题」。

---

## 第 5 步：验证真的能出片

1. 浏览器打开 **http://localhost:3000**
2. 看页面**右上角**：应该是一个红点子 + **🔥 真实出片 · Agnes AI** 的徽标（不是灰色的「演示模式」）。
3. 左边选一张模型卡（随便哪张，都会走免费通道），提示词写英文效果更稳，例如：
   ```
   A cinematic shot of a cat walking on the beach at sunset, soft ocean waves, warm golden lighting
   ```
4. 点「🚀 开始生成」。
5. 右边任务队列出现任务卡，状态在 排队→预处理→生成中→审核中→完成 之间走，等大约 1–3 分钟。
6. **成功的标志**：
   - 任务卡显示「已完成」、进度 100%；
   - 出现「⬇ 下载视频」按钮，点它保存下来的是一个 `.mp4` 文件（能用播放器打开、有画面有声音）；

> 第一次提交如果失败并提示「队列繁忙……已自动重试 3 次仍失败」：这不是你的操作问题，是 Agnes 免费通道高峰期被打满。等 5–10 分钟再点一次「开始生成」即可，失败不收费、也不会重复扣任何费用。

## Key 泄露了怎么办（轮换：删旧建新）

只要这把 Key 出现过在任何可能被第三人看到的载体里（聊天记录、文档、截图、旧版本文件、群聊），就当它已经泄露，按下面步骤作废重办（5 分钟）：

1. 打开 Agnes 开放平台（你当初注册的站点，国内是 platform.agnes-ai.cn）→ **API Keys / 密钥管理**页；
2. **删除**旧 Key——删除立即生效，旧 Key 当场失效，别人有也刷不出东西；
3. 点 **创建密钥**，名字随意（如 `dreamforge-新`），复制新 Key（只显示一次，先粘记事本）；
4. 更新系统环境变量：Windows 键搜「编辑系统环境变量」→「环境变量」→ 上半部分「用户变量」里找到 `AGNES_API_KEY` → 双击，粘贴新值 → 确定；
   （如果 .env 里也写过旧 Key，一并换掉；注意**系统环境变量优先于 .env**）
5. **关掉所有旧命令行窗口**，重开一个，启动 DreamForge，右上角显示「🔥 真实出片 · Agnes AI」即成功。

> 轮换后建议回平台确认旧 Key 状态为「已删除」，并观察一两天用量是否归零。

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 顶栏还是「演示模式」 | Key 没读到。按顺序查：① .env 里 `AGNES_API_KEY=` 等号后确实粘了字符；② 保存过记事本；③ 重启过 start.bat；④ 系统环境变量里有没有一个**旧的/错的** `AGNES_API_KEY`（它优先于 .env，见下条） |
| 换了新 Key 但不生效 | 系统环境变量优先于 .env。改法：Windows 搜索「编辑系统环境变量」→「环境变量」→ 在上半部分「用户变量」里找到 `AGNES_API_KEY` → 双击改值，或删掉这一行让 .env 接管 → 改完**关掉所有命令行窗口重开**再启动 |
| 提示「401 / API Key 无效」 | Agnes 侧拒绝了这个 Key。按可能性排查：① **接口地址与 Key 不匹配**——国内 Key 要配 `api.agnes-ai.cn`（不是 `apihub.agnes-ai.cn`！）、国际 Key 配 `apihub.agnes-ai.com`；本机已设国内接口，Key 必须在国内站创建；② 复制时缺了字符（应约 51 位、`sk-` 开头）——回国内站 API Keys 页逐字符比对；③ Key 在平台上被删了/停了；④ 刚创建的 Key 还没激活，等 2 分钟再试。最稳妥：在平台上删掉可疑 Key，重新创建一个，再更新系统环境变量 |
| 提示「队列繁忙」 | Agnes 免费通道高峰期容量满。程序已自动重试 3 次；仍失败就过几分钟再来，失败不收费 |
| 想传首帧图（图生视频） | 免费通道不支持。点首帧图区域的「⚡ 切换到火山方舟通道」一键切换；没配火山 Key 会弹出配置面板，现场填完即用 |
| 想强制走火山方舟 | 最快：页面顶栏点「⇄ 切换通道 → 火山方舟 → 保存并切换」；也可以传统方式：在 .env 里加一行 `DREAMFORGE_PROVIDER=volcengine`，保存重启 |
| 视频只有 720P / 时长被截到 12 秒 | 免费通道上限就是这样。要 1080P / 2K / 更长，需要 Agnes 付费模型或火山方舟 |
| 「限时免费」以后收费了怎么办 | 程序不用改：在页面顶栏「⇄ 切换通道 → 通道配置」把火山方舟的 Key 填上、切过去即可（Key 自动写进 .env）；或按传统方式改 .env 后重启 |

## 这个通道在程序里是怎么跑的（好奇的话）

- `models.config.json` 的 `providers.agnes` 段：4 个产品模型全部映射到上游 `agnes-video-2.5-flash`，时长超 12 秒自动截到 12、1080p 自动降到 720P（免费通道上限），收敛后的真实参数会显示在任务卡上。
- `server.js` 里 `submitUpstream()` / `pollProviderTasks()` 的 agnes 分支：提交到 `POST /v1/videos`，轮询 `GET /agnesapi?video_id=…&model_name=…`，拿到成品地址后下载转存到本地再给你下载（上游链接有时效）。
- 遇到 429 / 5xx 会自动退避重试（5s / 15s / 30s，共 3 次），这是按 Agnes 官方文档建议做的。
