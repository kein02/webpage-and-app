## 首次使用与回归

首页提供可跳过的引擎设置入口；引导按账号和浏览器保存显示状态，可以重新打开。引擎页采用选择方式、测试保存、开始出图三个步骤，不强制阻挡创作。

已验证无模型的 ComfyUI 不再误报可用；缺少基础工作流节点的档位不会出现在列表。Agnes 连接检测检查实际图片模型，配置修改会清除旧的检测结果。视频配置、模型权限与 API 额度分开表述，不承诺仅填 Key 就一定可生成。

FFmpeg 缺失或无法执行时，引擎页和短剧页显示处理方法，合成按钮禁用；修复后可重新检测。后端也会在下载和合成镜头前返回明确的 503 提示。公开模式仍忽略站长密钥并保护账号素材。

浏览器回归覆盖引导跳过、重开、保存、缺模型、缺 FFmpeg 及修复后恢复按钮，另保留桌面与手机的全部页面、账号隔离、素材、任务、画布和套餐选择检查。

## 重跑

常规回归不调用付费 API：

```powershell
python tests/test_backend.py
python tests/test_public_security.py
python tests/test_release_browser.py
python tests/test_compose.py
```

以下脚本明确调用真实引擎。先启动 ComfyUI，并保持 8101 端口空闲：

```powershell
python tests/test_local.py
python tests/test_generation_live.py --comfy
```

`--cloud` 会提交两次付费图片请求和一次付费视频请求；`--video-only` 仅补测一次视频，不重复图片。需要本机模式可读取的 Agnes Key。短剧验收复用一条已完成视频作为两个镜头，检查中文字幕、合成、下载和素材记录，避免额外购买多条视频。结果写入 `tests/output/live-acceptance/summary.json`，不提交 Git。
