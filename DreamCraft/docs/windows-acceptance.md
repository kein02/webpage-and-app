# Windows 1.0.0 验收

日期：2026-11-08。交付文件：DreamCraft-Setup-1.0.0-x64.exe（37,060,189 字节）及 DreamCraft-Windows-1.0.0-x64.zip（49,678,167 字节）。校验值见 Release 的 SHA256SUMS.txt。

安装版提供简体中文/英文向导、目录选择、桌面及开始菜单快捷方式、卸载入口。便携版解压后双击 DreamCraft/DreamCraft.exe。启动器打开默认浏览器，关闭启动器停止网页服务。不需要 Python、Node.js 或管理员权限。工作区使用系统浏览器，配合原生启动窗口。

## 数据与依赖

- 正式数据保存在 %LOCALAPPDATA%\DreamCraft，独立于原项目。升级保留该目录。
- 包内只含代码、Python 运行时、前端构建和第三方依赖；没有作者的 .env、数据库、作品、JWT 密钥或引擎加密密钥。
- 使用运行电脑的 API 环境变量或使用者填写的配置。默认检测本机 127.0.0.1:8188 ComfyUI。
- ComfyUI、模型、GPU 环境不随包分发。
- 短剧合成仍需自行安装 FFmpeg，加入 PATH 或放在 EXE 同目录。包内使用说明已说明此依赖。
- 当前没有数字签名。目标 Windows 10/11 x64，已在当前 Windows 11 x64 实测；未在独立的全新 Windows 10 虚拟机验收。

## 验收

本次从安装程序安装到隔离目录后运行 EXE；测试时移除 Python、Node.js 的 PATH 和 API Key 环境变量，采用独立测试数据目录。

- 程序启动、只监听 127.0.0.1、首次无个人素材。
- 重复启动只打开已有实例，不启动第二个服务。
- 注册登录、引擎密钥加密保存、图片上传和预览、主要页面路由无 JavaScript 错误。
- 上一轮便携 EXE 使用当前本机 ComfyUI 真实 GPU 出图；最终依赖升级后再次完成网页直连 ComfyUI 图生图、素材保存及 3D 动画/暂停像素检查。重建 EXE 验证运行流程，未重复 GPU 生成，未调用付费云端接口。
- 重启后账号、配置和作品保留；端口被占用时自动改用空闲端口。
- 真实原生启动窗口可创建，关闭窗口后后端退出。
- 安装创建的桌面和开始菜单快捷方式目标正确，EXE 产品版本及卸载入口版本为 1.0.0。
- 卸载删除应用、快捷方式和卸载注册信息，保留正式用户数据目录中的标记文件及已有数据。
- 当前机器原生窗口检查曾出现明显启动延迟，随后通过；未测量其他电脑启动速度。
- 前端构建通过，保留原有 3D 分块体积提示。

## 重建

构建脚本 desktop/build.ps1 使用项目相对路径和 Python 参数，运行 PyInstaller 6.22.3。安装器使用 Inno Setup，图标及版本资源位于 desktop。
打包只添加前端 dist 和应用导入模块，不复制整个后端目录。每次构建写入独立时间戳目录，避免覆盖旧产物。

安装回归命令：`./tests/test_installer.ps1 -Python D:\Python\python.exe`。脚本拒绝覆盖已有安装或快捷方式，使用隔离数据并在结束时卸载测试应用。

新目录及干净公开副本的前端构建、12 项后端回归、11 组公开安全回归、本机/公开模式隔离及桌面/手机浏览器流程通过。最终前端依赖 npm audit 报告 0 项漏洞，3D 分块仍有体积提示。发布使用独立标签 dreamcraft-v1.0.0，未包含自动更新和数字签名。
