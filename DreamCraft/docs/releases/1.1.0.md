# DreamCraft 1.1.0

- Windows 启动器增加自动版本检查、手动检查和下载升级入口。
- 仅检查本仓库 DreamCraft 正式版本，安装前验证附件大小及 GitHub SHA256。
- 安装版自动调用安装器升级；便携版退出后替换程序目录，保留旧版备份。
- 数据继续保存在原目录，升级后自动重新打开工作区。下载或校验失败可继续使用当前版本。
- 增加可信 Authenticode 签名构建入口，覆盖应用、安装器与卸载器，要求 SHA256 和可信时间戳。
- 当前维护者尚未配置签名证书，本次公开包仍未签名；签名接入与实际已签名发布分开说明。
- GitHub 正式 1.0.3 安装包及便携包已在维护者本机下载、验哈希并完成回归。
- 真实云端视频补测仍被供应商「平台队列已满」阻塞，尚未验证云端视频到短剧成片。

升级到本版本前：1.0.x 没有应用内更新，请手动运行新版安装器，
或解压新版便携 ZIP。从 1.1.0 起可使用启动器中的更新入口。
