# DreamCraft 造梦工坊 1.0.0

Windows 10/11 x64 桌面版本，使用系统浏览器工作区和原生启动窗口，无需安装 Python 或 Node.js。

## 使用

- 安装版：运行 DreamCraft-Setup-1.0.0-x64.exe，按向导选择目录，可创建桌面和开始菜单快捷方式。
- 便携版：解压 ZIP，运行 DreamCraft 文件夹中的 EXE，保留 `_internal`。
- 先启动自己的 ComfyUI，或在引擎设置填写自己的 API。程序不提供公共算力或作者的密钥。
- 关闭原生启动窗口停止服务。升级及卸载保留 `%LOCALAPPDATA%\DreamCraft`，备份时应在停止服务后复制整个数据目录。

## 内容与边界

图像生成与编辑、视频平台适配、素材库、任务中心、画布、短剧合成、账号及团队。ComfyUI 与模型需另行安装，短剧合成另需 FFmpeg。

安装包带应用图标、1.0.0 版本资源、简体中文/英文向导及卸载入口。应用只监听本机，重复启动复用实例，端口冲突自动切换。

使用说明：[API 接入](https://github.com/kein02/webpage-and-app/blob/main/DreamCraft/docs/api-setup.md) · [ComfyUI 部署](https://github.com/kein02/webpage-and-app/blob/main/DreamCraft/docs/comfyui-setup.md) · [网页自部署](https://github.com/kein02/webpage-and-app/blob/main/DreamCraft/docs/deployment.md)。

当前没有自动更新和数字签名。目标系统 Windows 10/11 x64，已在当前 Windows 11 x64 验证；云端付费接口以模拟响应验收，实际生成取决于个人平台配置及余额。未内嵌浏览器，需系统默认浏览器。
