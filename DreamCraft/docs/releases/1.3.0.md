# DreamCraft 1.3.0

发布日期：2026-11-17。

## 数据目录迁移

- 启动器增加「迁移数据文件夹」：选择空文件夹，停止服务后迁移全部账号、项目、配置、密钥、上传素材、生成图片和视频、日志。
- 校验文件哈希、数据库和加密配置后启用新目录，移除旧数据。后续只向新目录写入，不自动另存一份。
- Windows 注册表仅记住所选路径；新位置不可访问时明确报错，避免误开空白数据库。迁移失败保留原数据；旧文件清理失败会提示并记录。
- 本机模式的云端图片、视频结果下载到当前数据目录的 exports，避免仅保留供应商临时链接。既有远程素材不会自动补下载。

## 使用

升级前保存项目并等待任务结束。运行新版安装器，或解压便携包后运行 DreamCraft.exe；在启动窗口选择「迁移数据文件夹」。应用安装位置与个人数据位置可以不同。

ComfyUI、模型、浏览器缓存和浏览器手动下载目录独立管理。浏览器中的未保存草稿和浏览器配置不属于应用数据目录。数据备份包含密钥，请私人保存。

此版本未签名。真实付费云端视频与完整短剧生成链路的既有验收限制不变。

## 下载与验证

Release 附件包含 Windows x64 安装器、便携 ZIP、SHA256SUMS.txt 和本说明。
安装版无需 Python、Node.js 或管理员权限；便携版完整解压后运行 DreamCraft/DreamCraft.exe。
1.1.0 起可通过启动器检查更新；1.0.x 用户先手动安装新版一次。

版本元数据、数据迁移及便携 EXE 的完整迁移、重启和备份恢复已在本机通过隔离测试。
正式附件由 GitHub Windows 发布流程重新构建，经过安装/卸载、便携运行、备份恢复和旧版升级检查后发布。
详细验证范围见 docs/windows-acceptance.md。
