# DreamCraft 1.0.3

## 首次使用

- 首页增加可跳过的引擎入口；引擎设置提供选择、测试保存、开始创作三个步骤，可随时重新打开。
- ComfyUI 服务可达但未安装模型时不再误报成功；档位列表排除缺少基础工作流节点的模型。
- Agnes 图片连接检测检查实际模型列表，更改配置后清除旧检测结果。
- 引擎页和短剧页检测 FFmpeg 是否可执行，缺失时给出安装及重启提示；修复后可重新检测并恢复合成。

## 验证范围

- 本机真实批量出图、参考图生成、蒙版重绘、扩图、透明抠图、换背景、素材保存与浏览器下载通过。
- Agnes 真实图片生成与参考图编辑通过；视频平台返回队列已满，云端视频及其短剧成片尚未通过。
- 自动化覆盖首次引导、缺模型、缺 FFmpeg、账号与素材隔离及主要页面。
- 没有另一台电脑，未进行独立电脑安装验收。ComfyUI、模型、FFmpeg 和个人 API Key 仍需使用者自行提供。

安装版与便携版不包含开发者密钥、数据库或作品。不包含自动更新和数字签名。
