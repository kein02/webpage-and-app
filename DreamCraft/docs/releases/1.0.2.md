# DreamCraft 造梦工坊 1.0.2

- 修复账号切换时旧请求可能清除新账号登录态或覆盖媒体令牌的问题；登录前等待退出请求完成。
- ComfyUI 后端现在识别已安装的 SDXL 和 Lightning 文件名，并在工作流中使用实际识别到的文件。
- 短剧批量提交在创建任务前校验全部分镜、时长及所需积分，避免前序镜头已开始而后续校验失败；渲染期间禁止重复提交，合成期间禁止重新提交。
- 图像编辑、智能体和本机直连生成的内嵌图片统一保存为文件，素材库和任务记录不再累积大型 base64 内容。
- 修复上传素材用作视频参考帧时向云端传递不可访问的本地路径，以及极窄图片高清化尺寸取整为零的问题。
- 默认停止网页服务时保留外部 ComfyUI；支持指定后端端口，显式使用 `--comfy` 才停止 8188。
- 扩充浏览器回归，覆盖全部 15 个页面的桌面/手机布局、画布导出、团队成员操作、短剧状态和套餐选择。

Windows 10/11 x64。升级前关闭程序并备份 `%LOCALAPPDATA%\DreamCraft`；安装和卸载保留个人数据。自行配置 API 或 ComfyUI，模型及 FFmpeg 需另行安装。当前没有自动更新和数字签名。
