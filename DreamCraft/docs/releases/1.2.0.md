# DreamCraft 1.2.0

## 工作区

- 画布与短剧支持项目自动保存、打开、重命名和删除；画布支持撤销、重做。
- 素材支持分页、搜索、名称与标签、回收站恢复，以及所选本机文件 ZIP 导出。
- 任务中心增加详情、参数复用、失败重试和查询恢复；已保存平台编号的视频任务重启后查询原任务，避免重复提交。

## 创作与桌面

- 短剧支持逐镜头提示词、镜头运动、时长、增删排序、单镜头生成，以及字幕、片段裁剪和背景音乐音量。
- 图像工具和画布支持 ComfyUI 模型 AI 放大，并保留可明确选择的普通 Lanczos 插值。
- 桌面启动器提供数据备份与恢复，恢复前自动备份当前数据；校验损坏文件、密钥和不安全路径，失败时回滚。
- 修复 FFmpeg 循环配乐可能导致合成任务无法结束的问题，完善长字幕定位和裁剪越界提示。

## 使用与验证

1.1.0、1.1.1 用户可通过启动器检查更新，也可手动运行新版安装器；1.0.x 用户需先手动安装新版。升级前建议备份数据目录。备份 ZIP 包含全部本机账号、素材与 API 密钥，未额外加密，请保存在私人位置。

AI 放大需另行安装兼容模型。维护者本机已用 RealESRGAN_x4plus 完成 256×192 → 1024×768 的真实 GPU 推理和透明通道验证；这不代表大图性能或画质验收。程序不包含 ComfyUI、模型、FFmpeg 或公共 API。

离线后端、安全、项目、编辑、备份和浏览器回归，以及真实 FFmpeg 合成和桌面恢复已通过。本版仍未签名。真实付费云端视频及其完整短剧链路尚未完成验收。
