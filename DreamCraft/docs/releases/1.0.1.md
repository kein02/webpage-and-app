# DreamCraft 造梦工坊 1.0.1

- Windows 安装版、便携版及 SHA256 校验文件由 GitHub Actions 自动构建，通过回归检查后发布。
- 统一管理应用版本，网页顶栏、启动窗口、后端 API、EXE 属性及安装器保持一致。
- 补充后续版本的构建、更新说明与发布流程。

Windows 10/11 x64。安装版运行 `DreamCraft-Setup-1.0.1-x64.exe`；便携版解压 `DreamCraft-Windows-1.0.1-x64.zip`，保留 `_internal` 目录。升级前关闭应用并备份 `%LOCALAPPDATA%\DreamCraft`，升级和卸载保留个人数据。

需自行配置 API 或启动 ComfyUI；不包含模型、公共算力或作者密钥。短剧合成需另装 FFmpeg。使用系统浏览器，无需 Python/Node.js。当前没有自动更新及数字签名。
