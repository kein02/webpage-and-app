造梦工坊 DreamCraft - Windows x64 便携版

1. 解压整个压缩包，双击 DreamCraft 文件夹中的 DreamCraft.exe。
2. 稍等片刻，程序自动打开默认浏览器。启动窗口须保持开启。
3. 先启动你自己的 ComfyUI（默认 127.0.0.1:8188），或在引擎设置填写自己的 API Key。
4. 关闭 DreamCraft 启动窗口即可停止本机网页服务。只关闭浏览器不会停止服务。

不需要安装 Python 或 Node.js，不需要管理员权限。目标系统 Windows 10/11 64 位。
不包含 ComfyUI、模型、云端 API 密钥或作者的个人数据。
程序可以使用运行电脑已有的 API 环境变量，不会携带打包电脑的环境变量。
首次使用建议进入引擎设置测试连接；ComfyUI 未启动时无法使用本机生成。

账号、素材、日志及加密密钥保存在：
%LOCALAPPDATA%\DreamCraft
启动窗口的“打开数据目录”按钮可以打开该目录。
升级时替换应用文件夹，保留上述数据目录即可。备份时需备份整个数据目录。
1.2.0 起启动窗口提供“备份数据”“恢复备份”。先保存网页内容，再选择数据目录之外的 ZIP。
备份包含全部账号、项目、素材和 API 密钥，未额外加密，请妥善保管。
恢复会替换当前数据，恢复前自动在数据目录上一级保存旧数据 ZIP，然后重新启动服务。
启动窗口会自动检查新版，也可点击“检查更新”，确认后下载、验哈希并升级。
1.0.x 用户需要手动安装新版一次。便携更新保留 previous 旧版备份。
当前发行包未配置可信签名证书，Windows 可能显示未知发布者提示。

短剧视频合成需要 FFmpeg：可自行安装 ffmpeg 并加入 PATH，或将 ffmpeg.exe
放在 DreamCraft.exe 同目录。此包不包含 FFmpeg；没有 FFmpeg 时仅合成功能不可用。
FFmpeg 由其项目独立发布：https://ffmpeg.org/

应用只监听本机地址。不要将此便携版通过端口转发直接公开为多人站点。
重复双击会打开已运行的页面。端口冲突时自动选择空闲端口，地址变化后浏览器配置需重新填写。
